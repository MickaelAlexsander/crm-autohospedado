
# CRM Autohospedado

Sistema de gestão de clientes para pequenos negócios de serviços.

O objetivo é oferecer uma solução open source, modular e fácil de instalar, permitindo que pequenos negócios organizem seus clientes, funcionários e atendimentos.

## Objetivos

- Cadastro e gerenciamento de clientes.
- Controle de funcionários e permissões de acesso.
- Registro de atendimentos e histórico de visitas.
- Acompanhamento de retornos e agendamentos.
- Atalhos para contato com clientes pelo WhatsApp.
- Exportação de dados.
- Instalação simplificada com Docker Compose.

## Público-alvo

Pequenos negócios de serviços, como barbearias,
clínicas e outros estabelecimentos.

## Tecnologias

As tecnologias serão definidas durante a fase inicial
do desenvolvimento.

## Instalação

As instruções de instalação serão adicionadas
conforme a infraestrutura do projeto for implementada.
