
# Arquitetura inicial

## Decisões definidas

- Aplicação web.
- Projeto open source.
- Instalação autohospedada.
- Docker Compose como caminho principal.
- Perfis de administrador e funcionário.
- Integração com WhatsApp por links e mensagens pré-preenchidas.
- Funcionalidade de exportação de dados.

## Decisões pendentes

- Framework do frontend.
- Tecnologia do backend.
- Banco de dados.
- Estratégia de autenticação e autorização.
- Ferramentas de testes.
- Estratégia de backup e atualização.
