
# Como contribuir

Obrigado pelo interesse em contribuir com o projeto!

## Fluxo de contribuição

1. Faça um fork do repositório.
2. Crie uma branch para sua alteração.
3. Implemente e teste as mudanças.
4. Faça commits com mensagens descritivas.
5. Abra um Pull Request explicando as alterações.

## Diretrizes

- Mantenha o código organizado e legível.
- Documente mudanças importantes.
- Não envie senhas, tokens ou dados pessoais.
- Descreva os testes realizados.
